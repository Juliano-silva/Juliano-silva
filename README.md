<summary>Bc Senhas</summary>
  Gostaria de falar sobre um projeto que eu acabei de terminar e que eu tive muito orgulho dos resultados incríveis!

Nos últimos dois meses, criei um Gerenciador de Senhas na empresa onde trabalho, com o objetivo de melhorar o atendimento ao público e organizar o fluxo de pessoas.

Uma coisa que notei logo no início foi que o sistema antigo não tinha um telão para exibir e chamar senhas, o que afetava diretamente a organização e a experiência dos atendentes e do gerente.

Então, decidi reunir a equipe e apresentar uma solução completa, definindo a abordagem técnica:

Que iria fazer um novo Gerenciador de senhas utilizando (Flask , Python , Javascript e Supabase)

A solução foi construída pensando em performance, escalabilidade e usabilidade.

🔄Durante o desenvolvimento:
 * Comecei usando a API do Google Sheets como Banco de Dados
 * Notei que havia limitações de performance e escalabilidade
 * Mudei completamente para o Supabase, melhorando a aplicação

Resultados ?
* O sistema agora é mais rápido, estável e organizado
* Implementamos um telão para chamar senhas
* A gestão e o controle dos dados estão melhores
* A estrutura está pronta para crescer

Além disso, trabalhei diretamente em:
A arquitetura da aplicação
Desenvolvimento Full-Stack
Modelagem e estruturação de dados
Controle de acesso e organização do sistema
Eu desenvolvi todo o projeto sozinho desde o inicio 

Esse projeto mostra que eu sou capaz de:
✅ Identificar problemas reais
✅ Propor e defender soluções técnicas
✅ Tomar decisões estratégicas
✅ Entregar soluções que geram valor
